# AI Customer Support & Resolution Agent

An AI-powered customer support system for a fictional e-commerce company, ShopEase.

## Objective
The system will use LLMs, RAG, agentic workflows, tool calling, memory, guardrails, and evaluation to handle common customer support requests.

## Planned Capabilities

- RAG-based knowledge retrieval
- Order status lookup
- Refund status lookup
- Support ticket creation
- Order cancellation
- Conversation memory
- Guardrails
- Evaluation
- FastAPI backend
- Streamlit interface
- Docker deployment

## Architecture
Customer → Streamlit → FastAPI → AI Agent → RAG / Tools / Memory → LLM → Response
